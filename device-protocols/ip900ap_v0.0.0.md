# Innovo IP900AP
The Innovo IP900AP is a sensor designed to measure SpO2 (and heart rate).

## Data Collection Instructions
1) Begin data collection on the EmotiBit oscilloscope
2) Begin performing procedure
3) After desired interval (every one second, two seconds, etc.), send the current SpO2 level or HR as a user note on the oscilloscope
4) Continue sending user notes containing IP900AP data until procedure is over
